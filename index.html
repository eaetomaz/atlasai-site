Aplicativo desktop

AtlasAI

Automação de repurposing de vídeo, do vídeo original à publicação no TikTok.

O que é

O AtlasAI é um aplicativo desktop (Windows) de uso individual que automatiza a criação de vídeos curtos a partir de conteúdo já existente. Ele roda localmente na máquina do usuário — não é um serviço web hospedado publicamente.

Como funciona

  • Baixa e transcreve o vídeo de origem localmente.
  • Usa um modelo de linguagem (Google Gemini) para gerar, avaliar e melhorar o roteiro e a metadata do vídeo curto (título, descrição).
  • Monta o vídeo final localmente.
  • Publica o resultado na conta do TikTok do próprio usuário, mediante autorização OAuth explícita concedida por ele.

Integração com o TikTok

O AtlasAI usa a API oficial de publicação de conteúdo do TikTok (Content Posting API) para publicar vídeos em nome do usuário, apenas na conta que o próprio usuário conectar via login OAuth do TikTok. O aplicativo não acessa, publica ou modifica nenhuma conta que não tenha sido explicitamente conectada pelo usuário.
